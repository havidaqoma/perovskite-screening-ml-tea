# Data Provenance and Licenses

Everything in `raw_data/` and the root-level CSVs was generated by this
project's own pipeline (feature engineering, XGBoost cascade, Monte Carlo TEA)
starting from public, permissively licensed sources:

| Input | Source | License / access | Used for |
|---|---|---|---|
| Computed material properties | Materials Project (next-gen.materialsproject.org) | CC BY 4.0, accessed via API with an institutional free key, 2026 | Training targets (bandgap, formation energy), novelty checks, stability (e-hull) checks |
| Elemental descriptors | `matminer`, `mendeleev` packages | BSD-3 / MIT (package licenses) | 8D/9D feature vectors |
| Dataset tensors (`*.pt`) | Derived from Materials Project entries by the notebook | CC BY 4.0 derivation; NOT redistributed here (regenerate with your own key) | Model training |
| Trained model (`xgboost_cascade_pipeline_2.joblib`) | This study | MIT (see LICENSE) | NOT redistributed here (30.5 MB; regenerate with the notebook) |
| All CSVs in `raw_data/` and root | Output of this repo's code on the inputs above | MIT / CC BY 4.0 attribution to Materials Project | Screening, TEA, figures |

Reusing any part of Materials Project data requires attribution to Materials
Project under CC BY 4.0. If you publish results based on this repository,
cite Materials Project as a data source and this repository via CITATION.cff.
